DIO/ODI Application Mappings

Application Mappings are derived analytical layers that project concepts from the canonical DIO/ODI Reference Vocabulary into external technical or conceptual domains.

Boundary: mappings do not modify the Reference Vocabulary, add canonical concept definitions, or imply that the external framework and DIO/ODI are equivalent. They make explicit, reviewable analytical relations between distinct conceptual systems.

DIO Reconstruction Failure Modes × RAG Pipeline

Maps current DIO Reconstruction Failure Modes to generic retrieval-augmented generation pipeline loci, mechanisms, observable symptoms, and hypothetical incidents.

Status: introduced in v0.2.0; included in DIO/ODI Reference Model v0.3.0 · v0.2.0 archive

HEM Heterogeneity Taxonomy × DIO Reconstruction Consequences

Uses the Heterogeneous Entity Matching taxonomy as an external axis for examining how heterogeneous input conditions may contribute to DIO reconstruction failures or increase Semantic Vulnerability.

Status: introduced in DIO/ODI Reference Model v0.3.0 · HEM source: 10.1016/j.datak.2026.102575

Architecture

Reference Vocabulary = what DIO/ODI concepts mean.
